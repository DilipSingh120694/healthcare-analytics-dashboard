# Healthcare Analytics Dashboard

An interactive Tableau dashboard exploring 55,500 synthetic patient
admission records from May 2019 to May 2024.

## What the dashboard shows

- Admission trends over time
- Billing by medical condition and insurance provider
- Length of stay across patient groups
- Test results by medical condition and admission type

## Interactive dashboard

[Explore the dashboard on Tableau Public](https://public.tableau.com/app/profile/dilip.rajpurohit1346/viz/HealthcareAnalyticsDashboard_17808326877770/Dashboard1)

## Data note

The dataset is synthetic. The dashboard demonstrates exploratory analysis
and visualisation design. Its results should not guide clinical decisions.
